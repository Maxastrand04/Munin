# ADR-0005: A Transcript ID and a standalone Deck ID are derived from their keys

**Decision:** The Transcript ID MUST be the first 12 hex characters of the SHA-256 of the Source's key, where a local Source's key is its resolved absolute path, a YouTube Source's key is its canonical watch URL, `https://www.youtube.com/watch?v=<id>`, and a KTH Play Source's key is its fixed lecture address, `https://play.kth.se/media/t/<entry id>`. The ID of a Deck read on its own MUST be derived the same way from the PDF's resolved absolute path. Neither ID may be random, prefixed, or stored separately from its key.

**Reason:** A random ID kept next to the key in the cache was weighed and lost, because a derived ID makes "at most one Transcript per Source" hold by construction: the same Source always maps to the same ID, and a cache lookup is a file lookup with no index to keep in sync. For YouTube, using the bare video ID as the Transcript ID was weighed and lost, because it breaks the 12-hex shape every lookup validates and lets a video ID and a path hash share one namespace. Hashing `youtube:<id>` was weighed and lost to the canonical URL, which is the same string the Timestamp links start from. KTH Play follows YouTube for the same reasons, and its key leaves out the slug, which the uploader can change and which appears in only one of the three link shapes. A standalone Deck follows a local Source. Hashing a prefixed key such as `deck:<path>` was weighed and lost, because no path is ever cached as both a Source and a standalone Deck, since ffmpeg cannot decode a PDF, so the two IDs never meet.

**Consequence:** Moving or renaming a file gives it a new Transcript, or a new standalone Deck. Changing the file in place does not, since the path is the key. Every accepted URL form of one video shares one Transcript, so adding a URL form must map it to the same canonical address. Any change to how paths resolve, such as `~` expansion or symlink handling, or to a canonical address's shape, changes IDs and orphans existing cache entries.

**Scope:** `src/munin/core/transcribe.py`, `transcribe`; `src/munin/core/kthplay.py`, `KthPlaySource.url`; `src/munin/core/slides.py`, `read_deck`
